## Phase 3 Task 3 formal security review fixes

- Added a hard stream-chunk limit and immediate empty-chunk rejection, so an upload cannot consume
  unbounded iterator work without consuming its byte limit.
- Tightened OOXML handling: DOCX/XLSX now require their own `[Content_Types].xml`, main document or
  workbook part, and matching main content type. ZIP EOCD metadata is preflighted before creating a
  full ZIP object; ZIP64, multi-disk, and over-member containers are refused.
- Reworked local-store containment checks to verify every existing root ancestor, root identity and
  resolved path before and after operations, plus file identity around write/read/delete. Test hooks
  prove static and check-to-operation reparse detection without requiring Windows administrator
  symlink privileges.
- Error wrappers no longer retain sensitive exception causes. Partial cleanup is attempted even for
  `BaseException` and reports a separate failure if cleanup cannot be confirmed.
- Review TDD RED: `9 failed`; final Task 3 plus Task 1/2 RAG focus: `69 passed`. Full backend:
  `358 passed, 1 skipped`; Ruff and `git diff --check` passed.
