# 行业监管政策核心摘要 (2026版)

## 1. 网络安全法核心要求
- **数据本地化**：关键信息基础设施运营者在中华人民共和国境内运营中收集和产生的个人信息和重要数据应当在境内存储。
- **安全等级保护**：国家实行网络安全等级保护制度。网络运营者应当按照网络安全等级保护制度的要求，履行安全保护义务，保障网络免受干扰、破坏或者未经授权的访问，防止网络数据泄露或者被窃取、篡改。
- **应急预案与演练**：制定网络安全事件应急预案，定期进行演练。

## 2. 数据安全法 (DSL)
- **数据分类分级**：国家建立数据分类分级保护制度，根据数据在经济社会发展中的重要程度，以及一旦遭到篡改、破坏、泄露或者非法获取、非法利用，对国家安全、公共利益或者个人、组织合法权益造成的危害程度，对数据实行分类分级保护。
- **重要数据目录**：各地区、各部门应当确定本地区、本部门以及相关行业、领域的重要数据具体目录，对列入目录的数据进行重点保护。
- **数据安全审查**：国家建立数据安全审查制度，对影响或者可能影响国家安全的数据处理活动进行国家安全审查。

## 3. 个人信息保护法 (PIPL)
- **最小必要原则**：处理个人信息应当具有明确、合理的目的，并应当与处理目的直接相关，采取对个人权益影响最小的方式。
- **知情同意**：处理个人信息应当取得个人同意（除法定情形外），并应当提供便捷的撤回同意的方式。
- **敏感个人信息处理**：只有在具有特定的目的和充分的必要性，并采取严格保护措施的情形下，方可处理敏感个人信息。

## 4. 行业合规指南 (金融/医疗)
- **金融行业**：金融机构必须建立全生命周期的数据安全管理体系，核心交易数据必须实现异地双活容灾备份，且审计日志至少保留 6 个月以上。
- **医疗行业**：电子病历及患者隐私信息必须进行脱敏或加密存储，未经授权严禁将医疗数据用于商业分析或模型训练。
