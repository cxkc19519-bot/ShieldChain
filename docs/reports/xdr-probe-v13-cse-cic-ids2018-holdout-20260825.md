## 6. 结论与限制

本轮证明冻结的 v13 候选可以在该独立日期的固定窗口中区分高强度 UDP 与 HTTP 洪泛，并保持两个非攻击窗口无洪泛行为发现。它增强了替代 XDR 的行为检测能力，但不能据此宣称生产准确率、全数据集召回率或未知攻击泛化能力。

后续仍需增加更多日期、网络结构、低速拒绝服务、合法高并发业务和真实镜像流量测试；生产环境还需要资产基线、容量自适应阈值、告警聚合和人工反馈闭环。
