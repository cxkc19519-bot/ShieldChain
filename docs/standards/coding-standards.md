# 编码标准

> 文档状态：当前参考文档。若与历史计划或验收快照冲突，以本文件和 `docs/README.md` 为准。

- 前端使用 React 与 TypeScript，后端使用 Python 与 FastAPI。
- 模块职责单一，公共接口使用显式类型和 Schema。
- 外部服务必须通过接口与适配器隔离，业务代码不得直接绑定供应商 SDK。
- 配置与代码分离，环境变量提供密钥，提交安全的 `.env.example` 而非 `.env`。
- 状态机转换、策略和工具参数校验采用确定性代码。
- 错误使用分类明确的异常，不吞掉异常，不以成功响应包装失败。
- 日志使用结构化字段和关联 ID，默认脱敏。
- 修改功能或修复缺陷时先定义失败测试或可复现实例。
- 保持文件聚焦；出现职责混杂时只做服务于当前任务的拆分。
