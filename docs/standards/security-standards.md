# 安全标准

> 文档状态：当前参考文档。若与历史计划或验收快照冲突，以本文件和 `docs/README.md` 为准。

- 遵循最小权限、默认拒绝、纵深防御和完整审计。
- API Key、密码、令牌、个人信息和真实安全数据不得提交或输出到日志。
- 对上传文件执行扩展名、MIME、大小、压缩炸弹和恶意内容检查；解析在受限环境进行。
- 所有输入执行 Schema、长度、枚举和业务范围校验。
- RAG 文档、工具输出和用户内容均视为不可信，隔离提示注入。
- 高风险工具调用必须通过策略和审批，禁止模型直接获取凭据。
- 对认证、授权、跨租户访问、注入、任意文件访问、SSRF 和依赖风险进行测试。
- 原始证据保存完整性哈希，禁止覆盖修改。
- 日志、报告和前端展示执行必要脱敏，并设置保留与删除策略。
