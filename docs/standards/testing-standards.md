# 测试标准

## 测试层级

- 单元测试：解析、分块、融合、状态转换、上下文装配、权限和参数校验。
- 集成测试：DeepSeek、Embedding、Milvus、Reranker 和仿真工具适配器。
- 工作流测试：正常闭环、证据不足、审批拒绝、工具失败、重新规划和预算终止。
- RAG 评测：使用固定中英文基准集。
- 安全测试：提示注入、越权调用、恶意文件、密钥泄漏和日志脱敏。
- 前端测试：核心流程、断线恢复和响应式布局。
- 演示回归：预置钓鱼剧本可在三分钟内稳定展示。

## 规则

- 默认测试不得产生真实云费用；真实服务测试必须显式启用并设置费用上限。
- 测试结果必须记录执行命令、通过数量、失败项和环境。
- 不允许通过删除或弱化测试来使构建通过。
- 阶段完成前运行该阶段单元、集成、安全和回归测试。
