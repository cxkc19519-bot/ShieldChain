# ShieldChain 总体设计

## 目标与范围

ShieldChain 是面向安全运营的离线可复现智能体研究系统。它把告警调查、知识依据、多智能体协作、受信工具执行、ReAct 恢复和审计报告组成闭环，同时把真实模型、真实设备和真实云适配器保持为显式未验收边界。

## 分层

浏览器端只消费公开投影；FastAPI 负责 HTTP 安全和用例编排；确定性领域服务负责权限、状态、预算和策略；适配器负责 SQLite、模型、向量库和安全设备。当前产品使用模块化单体，外部端口均可替换而不改变领域合同。

核心数据流是：告警进入事件仓储，调查运行器收集仿真证据，RAG 提供带引用的知识依据，多智能体生成结构化协作轨迹，受信工具网关执行经策略或人工批准的动作，验证失败进入有界 ReAct，最终报告只汇总公开证据—判断—动作—结果。

## 安全不变量

- tenant、principal、actor 和授权上下文不由浏览器自由提交。
- 所有变更使用 revision/CAS；审批、幂等键、策略结果和审计记录绑定 tenant。
- 模型输出不能直接执行工具；proposal 必须回到工具网关。
- 提示、思维链、凭据、原始设备 payload 和敏感证据不进入公开 API、日志或 UI。
- 未知状态、预算耗尽、循环、审批拒绝和验证不确定都失败关闭或转人工。

## 运行与部署

开发模式为 Windows 上的 React/Vite、FastAPI 和 SQLite。Compose 模式先迁移，再启动内部后端，最后启动非 root Nginx；只发布宿主机回环地址 8080。Liveness 只证明进程响应，readiness 同时检查数据库、精确 Alembic head 和生命周期。

当前 SQLite/单实例拓扑用于比赛演示，不承诺多副本、高可用或灾备。生产扩展需要受管数据库、平台密钥注入、镜像签名、网络策略、备份恢复和授权真实适配器验收。

## 质量模型

质量门禁覆盖 Ruff、Pytest、ESLint、TypeScript、Vitest、生产构建、迁移往返、固定 RAG 评测、PowerShell 合同、阶段 smoke、性能预算和容器静态合同。真实网络、模型规划、安全设备和本机 Docker 状态在交付清单中独立标记，不能由离线成功推断。
