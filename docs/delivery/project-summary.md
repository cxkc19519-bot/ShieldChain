# 项目总结

> 文档状态：当前参考（更新于 2026-08-23）。

ShieldChain 已从固定安全仿真演示演进为真实安全数据驱动的多智能体分析系统。项目能够接入 Wazuh 告警和离线 NTA 数据，使用七个专业智能体进行 ReAct 协作，并通过知识库、历史报告和四类只读 MCP 生成可追溯的安全运营报告。

## 已实现

- Wazuh 高风险告警接收、去重、持久化和前端展示；
- 总控、分诊、研判、检索、响应规划、验证和报告七个专业角色；
- 模型自主选择角色和只读工具的 ReAct 运行；
- 事件、告警、漏洞、弱密码四类 MCP；
- 运营响应规划角色生成严格零动作建议，服务端完成证据/目标/工具重绑定和版本化计划审计；
- 安全运营报告 Markdown、HTML、下载与预览；
- 本地知识库、LLM 语义分块、规则降级、混合检索和 Reranker；
- 智能助手对话、摘要记忆和历史报告检索；
- Windows 一键启动、Docker 服务器部署和本地 vLLM 覆盖配置；
- 中文公开审计、轨迹和失败状态。

## 当前边界

- 运营报告已关联严格计划，但报告级运行没有单一案件目标，只生成零动作建议，不自动执行真实处置；
- 本地 30B 模型服务启动依赖完整权重和两张可用 RTX 4090；
- SQLite 适合单实例演示，不代表生产高可用；
- 真实生产网络、镜像流量和大规模并发仍需授权环境验收；
- 共享服务器资源需要人工协调。

## 已删除

- 固定钓鱼模拟攻击功能和对应产品入口；
- Remotion 视频工程、比赛 MP4 和相关测试；
- 把固定顺序工作流宣传为自主智能体的表述。

## 下一步

1. 将案件级计划动作逐项接入可信工具审批、幂等、执行和验证边界；
2. 完成本地 Qwen3-30B-A3B 权重下载、vLLM 启动和工具调用验收；
3. 将 Wazuh 真实告警自动交给受控多智能体调查入口；
4. 补充漏洞和弱密码真实数据适配器；
5. 完成身份认证、TLS、备份恢复和生产数据库迁移；
6. 在授权网络中进行端到端检测与人工处置演练。
