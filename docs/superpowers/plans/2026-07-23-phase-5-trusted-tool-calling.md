# 阶段 5：可信工具调用实施计划

按 `docs/superpowers/specs/2026-07-23-phase-5-trusted-tool-calling-design.md` 实施。每个任务独立测试、审查和提交；默认离线，不提前实现阶段 6 ReAct，不接入真实安全设备。

## Task 1：核心领域合同与状态机

新增 `shieldchain/tools/domain.py` 及单元测试。定义工具、风险、调用状态、严格参数、可信请求、策略、审批、执行尝试、结果和验证合同；不可变、防御性冻结、UTC、UUID、长度、摘要和白名单状态跳转严格校验。合同不得包含 tenant/principal 覆盖字段、凭据、prompt、思维链、Shell、代码或任意 URL。

## Task 2：工具注册表与严格参数 Schema

实现固定版本注册表、具体参数解析和规范化摘要。拒绝重复注册、未知工具/版本、额外字段、无界字符串、动态 URL、代码字段、不安全超时/重试和缺少验证器的变更工具。注册四个离线工具定义，不执行动作。

## Task 3：租户化迁移与只追加仓储

新增可信调用、策略决策、审批、执行尝试、验证和控制状态表。调用聚合使用 revision/CAS；审批、尝试、验证和审计只追加。实现 tenant/run scoped 仓储、幂等键与请求摘要冲突检测，并完成 Alembic 升降升及跨租户测试。

## Task 4：确定性策略引擎

按固定顺序实现全局开关、工具身份、角色权限、案件/证据、参数/目标、风险、模式、速率和预算判断。输出 allow/deny/approval_required 与稳定原因码；HTTP/模型不能覆盖风险或策略。覆盖仿真/真实模式矩阵、证据失效和默认拒绝。

## Task 5：审批服务

实现请求摘要绑定、有效期、撤销、批准/拒绝、调用者与高风险审批者分离，以及仿真自动策略记录。参数或工具版本变化使审批失效；审批不触发执行。测试越权、重复、过期、跨租户和竞态。

## Task 6：可信工具网关

实现提议→策略→审批→执行租约→适配器→验证的固定流水线。适配器只接收已解析参数，不持有模型上下文；工具输出清洗后保存。状态、尝试与审计原子提交，超时表示未知，未知结果不能宣称成功。

## Task 7：幂等、超时、受限重试与恢复

同键同请求返回已有结果，同键不同请求拒绝。只读/安全操作按注册定义有限重试；高风险失败或超时先查询状态，不盲目重放。实现过期租约恢复、预算计数和人工复核分支。

## Task 8：离线仿真适配器与执行后验证

复用现有 `SimulatedFirewall` 并新增受限的防火墙查询、终端隔离和账号禁用仿真端口；固定测试数据，不访问网络或系统命令。每个变更工具配只读验证器和可恢复状态查询，结果通过不可信输出包络进入上下文。

## Task 9：暂停、取消、恢复、紧急停止与全局开关

实现单调用控制状态和全局自动化控制。停止后不发新租约；已发出的动作不能伪装撤回，必须查询并验证。所有控制变更记录主体、原因码、revision 和审计；覆盖并发和恢复测试。

## Task 10：阶段 4 编排边界接线

把 `awaiting_trusted_execution` 与可信网关的已验证终态连接。只有验证成功才能进入验证角色；拒绝、取消、未知和紧急停止进入人工复核。响应角色继续只输出 proposed actions，不获得工具端口。

## Task 11：只读轨迹 API、审批/控制 API 与最小处置中心

提供 tenant-bound 调用轨迹、审批、取消、恢复和紧急停止 API；服务端绑定身份与权限。实现最小处置中心，展示策略、审批、尝试、验证、原因码和引用，不展示私有数据或原始工具输出。覆盖严格前后端契约和泄漏测试。

## Task 12：阶段 smoke 与出口门禁

使用临时 SQLite、迁移和离线仿真适配器完成 proposed action→策略→审批→幂等执行→验证→编排恢复 smoke，同时覆盖审批拒绝、同键冲突、高风险未知结果和紧急停止。扩展验证脚本、迁移往返、安全评测、文档、路线图和开发日志，最后运行完整门禁。

## 快速执行规则

- 同一时间只有一个实现者修改工作区；每个 Task 独立提交。
- Task 1–2 不接数据库，Task 3 才迁移；Task 6 前不执行工具；Task 10 前不接编排器；Task 11 前不开放变更 API。
- 每个任务跑聚焦测试；Task 3、6、8、10 后跑跨模块回归；Task 12 才跑完整门禁。
- 默认测试清除所有 live 开关，不联网、不产生费用、不执行 Shell、不操作真实设备。
- 不推送、不合并，除非用户明确要求。
