# 阶段 7：完整安全运营前端实施计划

> 文档状态：历史规划/设计归档。用于追溯阶段性决策，不代表当前运行方式；现行架构以 `docs/README.md` 及各目录现行文档为准。

按 `docs/superpowers/specs/2026-07-24-phase-7-complete-frontend-design.md` 实施。每个 Task 独立测试和提交；默认离线，不伪造真实云或设备成功，不扩大服务端权限边界。

## Task 1：统一应用壳与设计系统

重构品牌栏、响应式导航、内容宽度、状态徽标、按钮、表单、指标卡、空/错/加载组件和基础可访问性；保持现有路由与功能不退化。

## Task 2：共享案件/运行上下文

实现 URL + sessionStorage 的 `incident_id`/`run_id` 上下文、手工切换、请求取消和跨页导航；不存储 tenant、principal、权限或凭据。

## Task 3：运营总览

用健康检查与公开调查数据构建状态、风险、证据、处置和验证概览；后端缺少聚合时新增最小 tenant-bound 只读端点，覆盖空状态和失败关闭。

## Task 4：事件调查工作台

重排事件头部、攻击路径、调查阶段、证据链、研判、工具结果、验证和审计时间线；启动调查后写入共享上下文，保留仿真/失败模式边界。

## Task 5：智能体与 ReAct 工作台

在同一页面组合阶段 4 协作轨迹和阶段 6 ReAct 轨迹，展示预算、角色、交接、观察、分类、计划差异、决策和引用；支持安全的人工接管/恢复。

## Task 6：知识库工作台

统一上传、文档状态、问题输入、回答、引用、拒答和失败状态；增强键盘、移动端和安全渲染测试，不改变失败关闭语义。

## Task 7：处置中心

按风险与状态显示策略、审批、执行尝试、验证、证据、暂停/恢复/取消和紧急停止；动作按钮按服务端状态约束，失败后刷新可信状态。

## Task 8：报告与审计

移除占位页，组合公开事件、审计、智能体、工具和 ReAct 投影生成只读报告、结论状态和有序审计；缺失数据明确标注，不推断私有内容。

## Task 9：全局可访问性、安全与响应式回归

覆盖 320px/桌面布局、键盘焦点、语义标题、aria 状态、减少动画偏好、请求取消、错误边界和禁止敏感字段渲染；集中修复跨页一致性问题。

## Task 10：Phase 7 smoke、完整门禁与文档

新增跨页离线 smoke 和脚本合同，更新 README、架构、运维、路线图和日志；运行完整后端/前端、迁移、RAG、安全及 Phase 3–7 smoke。

## 快速执行规则

- 每个 Task 独立提交；先测试后实现，聚焦回归通过再进入下一 Task。
- Task 2 前不引入共享运行状态；Task 8 前不实现报告页；Task 10 才修改完整验证入口。
- 前端不持有或提交 tenant、actor、权限、分类、风险和预算。
- 不联网、不产生费用、不调用真实设备，不推送、不合并，除非用户明确要求。
