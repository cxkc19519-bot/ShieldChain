# SAGA Phase 0 Documentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a reviewable, internally consistent Phase 0 documentation baseline that separates the SAGA paper protocol from reproduction engineering and future tool-authorization research, without writing protocol implementation code.

**Architecture:** Treat the paper as the normative protocol source, the approved design specification as the decision record, and the authors' repository only as non-normative implementation evidence. Build the Phase 0 documents as a cross-linked set with the feature-source matrix at the center; every protocol statement, ambiguity, security claim, experiment, and later implementation phase must map back to that matrix.

**Tech Stack:** Markdown, PowerShell, ripgrep, Git. No Python package, FastAPI service, cryptographic implementation, database, container, or ProVerif model is created in Phase 0.

## Global Constraints

- The paper protocol text is the sole normative source; the authors' code cannot override it.
- Keep exactly these feature-source categories: `论文原始设计`, `复现工程补充`, `后续创新扩展`.
- The base ACT plaintext remains exactly `nonce`, `issued_at`, `expires_at`, `q_max`, and the initiating Agent access-control public key.
- Document the approved cryptographic profile exactly: Ed25519 signatures, X25519 access-control/OTK keys, HKDF-SHA256 with `salt=None` and `info=b"SAGA-ACT-DERIVE/v1"`, and ChaCha20-Poly1305 with `aad=b"SAGA-ACT/v1"`.
- Document the approved password profile exactly: scrypt with `N=2^15`, `r=8`, `p=1`, `dkLen=32`, and a fresh 16-byte cryptographically secure salt.
- Policy updates and Agent deactivation block new discovery/OTK issuance; already issued ACTs expire naturally or exhaust `q_max` in the base reproduction.
- ProVerif is mandatory before the base SAGA reproduction can be declared complete.
- Real Provider/Agent networking and mutual TLS are mandatory before the base SAGA reproduction can be declared complete.
- Performance passes on reproducible directional trends with environment and deviation reporting, not cross-hardware absolute equality.
- Do not create `feature/agent-tool-authorization` until the complete base-reproduction gate passes.
- Do not write formal protocol implementation code during Phase 0.
- Do not commit the local source PDF, requirements DOCX, Word lock files, or temporary render artifacts.
