# ShieldChain 产品需求

> 文档状态：当前参考（更新于 2026-08-08）。本需求替代以固定钓鱼仿真为核心的早期阶段需求。

## 产品目标

构建可在比赛和实验室环境运行的安全多智能体系统，接入真实或可追溯离线安全数据，自动完成告警分诊、威胁研判、知识检索、响应建议、验证计划和安全运营报告，同时保持人工监督和审计边界。

## 用户

- 安全运营人员：查看告警、报告、证据和建议；
- 复核人员：确认高风险结论和处置前置条件；
- 知识库管理员：管理文档、版本、分块和索引；
- 系统管理员：配置 Wazuh、模型、存储和访问边界。

## 功能需求

### 真实数据接入

- 接收 Wazuh 高风险告警并持久化；
- 支持离线 NTA 数据集用于无镜像流量环境的可重复演示；
- 提供事件、告警、漏洞、弱密码四类只读工具；
- 去重、时间窗口关联、幂等接收和失败重试。

### 多智能体

- 启用总控、告警分诊、威胁研判、知识检索、响应规划、验证和报告七个角色；
- 使用 ReAct 自主选择角色和工具，而非固定执行顺序；
- 服务端强制预算、循环检测、输出模式和停止条件；
- 模型异常时保留确定性结果并转人工。

### 安全运营报告

- 校验开始时间、结束时间和时区；
- 按任务自主选择只读 MCP；
- 分析工具结果并输出事实、风险、限制和建议；
- 生成 Markdown、HTML 和页面预览；
- 报告持久化并可供智能助手检索。

### RAG 与助手

- 知识库、文档版本、分块、索引和会话在重启后继续存在；
- 支持 LLM 语义分块与规则降级；
- 支持 BM25、BGE-M3、Milvus、融合与 BGE Reranker；
- 可查看具体分块、删除文档或知识库、重建索引；
- 助手基于知识库和历史报告回答，保存对话与摘要记忆。

### 模型

- 支持 OpenAI 兼容接口；
- 可使用外部 DeepSeek API；
- 可使用本地 vLLM Qwen3-30B-A3B FP8；
- 不把模型供应商写死为业务能力；
- 密钥和私有上下文不得出现在前端、日志或仓库。

## 非功能需求

- 所有变更动作默认拒绝，必须经过策略和人工审批；
- 数据按租户、运行和角色隔离；
- 接口失败安全关闭，不能伪造成功；
- 日志、审计和报告使用中文公开摘要；
- 支持 Windows 本地和 Docker 服务器部署；
- 持久化数据可备份，删除操作需确认并同步清理关联索引。

## 当前非目标

- 无人监督的自动封禁、隔离或账户停用；
- 在共享 GPU 服务器上自动抢占资源；
- 把离线数据集结果宣传为真实生产检测效果；
- 展示模型私有思维链或原始安全设备载荷；
- 在版本库分发模型权重、真实告警或凭据。
