# 产品需求

## 产品名称

盾链智御——基于可信工具调用与多智能体协同的网络安全运营超级智能体。

## 核心用户与价值

面向企业安全运营人员及缺乏深度安全经验的使用者，将分散告警、调查、研判、处置、验证和报告工作整合为可解释、可审计、可控制的自动化闭环。

## 核心演示场景

钓鱼附件触发可疑 PowerShell，终端连接恶意 IP，账号凭据失陷并异常访问服务器。系统关联流量、端点、身份和日志，结合 RAG 知识完成研判，随后通过可信工具调用封禁 IP、隔离终端、禁用账号，验证威胁消失并生成报告。

## 必须实现

- 多源告警聚合、误报研判、攻击路径和证据链展示。
- 超级智能体自主规划及多个专业智能体协同。
- 共享案件上下文、角色私有上下文和结构化交接。
- 多格式知识库、DeepSeek 语义分块、查询改写。
- BGE-M3 中英文 Embedding、托管 Milvus、BM25 与向量混合召回。
- BGE-Reranker-v2-m3 交叉编码重排、引用溯源和无依据拒答。
- 可信工具网关、风险分级、审批、幂等、审计、验证及紧急停止。
- ReAct 式观察、反馈和重新规划，带循环、时间、Token、费用限制。
- 真实模式分级自治；仿真模式支持零人工干预。
- 淡蓝色、简洁直观的安全运营前端。
- Windows 本机直接运行；后续提供 Docker Compose 一键部署。
- 源代码、设计、开发、测试和总结文档，以及 PPT 与三分钟以内演示视频。

## 初版外部条件

- LLM 使用 DeepSeek API。
- Embedding 与重排使用云端服务。
- 向量数据库使用托管 Milvus。
- 暂无深信服平台和真实安全设备接口，采用仿真数据与工具适配器。
- 获得权限后替换连接器，不改变上层智能体和工作流。

## 非目标

- 初版不在本机部署大模型、Embedding、Reranker 或 Milvus Standalone。
- 初版不连接真实生产防火墙、EDR 或身份系统。
- 不让 LLM 直接执行任意代码或绕过审批策略。
- 不把未经确认的模型输出自动写入长期知识库。

## 验收标准

- 主演示场景可重复、稳定地完成调查、处置、验证和报告闭环。
- 所有重要结论能追溯到原始证据或知识引用。
- 高风险动作无法绕过安全监督器。
- 服务失败时显式降级、重试、重新规划或转人工。
- Windows 本机可按文档启动，核心自动化测试和 RAG 回归评测通过。
