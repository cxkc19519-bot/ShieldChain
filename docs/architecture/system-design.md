# 系统架构

## 架构风格

初版采用“模块化单体＋可插拔外部服务”。本机只常驻 React 前端和 FastAPI 后端，多个智能体作为后端内部有清晰接口的模块运行。后续可按负载和企业部署要求拆分服务。

## 核心模块

- 前端：运营总览、事件调查、智能体工作台、知识库、处置中心、报告和审计。
- API 层：认证、授权、输入校验、限流、任务接口和实时进度。
- 超级智能体编排器：显式状态机、任务规划、角色调度、反馈和重新规划。
- 专业智能体：告警、调查、知识检索、响应处置、验证和报告。
- 上下文装配器：权限过滤、相关性选择、Token 预算、压缩和结构化交接。
- RAG 子系统：解析、分块、索引、改写、混合检索、重排、引用和评测。
- 可信工具网关：工具注册、策略校验、审批、执行、幂等和审计。
- 仿真层：流量、端点、身份、日志以及防火墙、EDR、账号工具模拟器。
- 状态与审计：SQLite 初版存储，保留迁移 PostgreSQL 的仓储接口。

## 设计原则

- 模型负责语义任务，权限、审批、工具参数和状态转换由确定性代码负责。
- 所有外部能力通过适配器接入。
- 事实、假设、模型结论、知识引用和工具结果采用不同数据类型。
- 不展示隐藏思维过程，展示可审计的“证据—判断—行动—结果”轨迹。
- 原始证据不可覆盖；所有关键状态变更可追溯。

## 主数据流

告警进入系统后建立案件；编排器并行收集多源证据，调用 RAG 获得知识依据，形成结构化研判与处置计划。可信工具网关执行风险校验和必要审批，工具执行后由验证智能体再次观测。验证失败触发限次重新规划，成功后关闭案件并生成报告。
