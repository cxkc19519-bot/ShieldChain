# 多智能体设计

## 角色

- 超级智能体：理解目标、建立计划、调度、汇总和重新规划。
- 告警研判智能体：聚合、去重、风险分级和误报判断。
- 威胁调查智能体：关联实体、构建时间线和证据图。
- 知识检索智能体：执行 RAG，只返回带来源的依据。
- 响应处置智能体：把已批准计划转换为可信工具调用请求。
- 验证智能体：检查处置后的目标状态。
- 报告智能体：依据已确认事实和审计记录生成报告。
- 安全监督器：确定性策略组件，不是拥有任意权限的 LLM 智能体。

## 协作约束

- 智能体不得直接修改其他角色的私有上下文。
- 交接使用结构化数据，包含结论、置信度、证据引用、未决问题和建议动作。
- 接收方不得把上游结论直接当成事实，必须能追溯证据。
- 每个角色只拥有完成职责所需的最小工具集合和数据权限。
- 工作流设置最大步骤、循环、时间、Token、费用和工具调用预算。

## 终止条件

- 威胁已验证消失并完成审计与报告。
- 证据不足或来源冲突，转人工判断。
- 高风险审批被拒绝。
- 达到任一预算或循环上限。
- 关键依赖不可用且不存在安全降级路径。
