# 可信工具调用规范

## 网关职责

所有安全动作必须经过可信工具网关。网关负责工具身份、调用者权限、参数 Schema、目标范围、风险、审批、幂等、频率、超时、重试、审计和结果验证。

## 风险策略

- 只读查询：满足权限和参数要求后自动执行。
- 低风险动作：默认自动执行，可由策略覆盖。
- 封禁 IP、隔离终端：真实模式可配置审批，仿真模式自动执行。
- 禁用账号等高风险动作：真实模式默认审批，仿真模式可自动执行。

## 安全约束

- 工具使用严格结构化参数，不接受任意 Shell 或模型生成代码。
- 调用前检查证据引用、目标身份、预期效果和回滚策略。
- 高风险失败不得盲目重复，先查询当前状态再决定重试。
- 使用幂等键避免重复封禁、隔离或禁用。
- 支持暂停、取消、恢复、紧急停止及全局自动化关闭。
- 工具结果属于不可信输入，进入模型前执行提示注入隔离和数据清洗。

## 审计字段

案件、计划、调用者、工具与版本、参数摘要、证据引用、策略结果、审批人或自动策略、时间、结果、验证、重试和关联调用。密钥及不必要的敏感数据不得进入审计日志。
