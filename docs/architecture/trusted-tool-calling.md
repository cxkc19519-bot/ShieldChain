# 可信工具调用规范

## 网关职责

所有安全动作必须经过可信工具网关。网关负责工具身份、调用者权限、参数 Schema、目标范围、风险、审批、幂等、频率、超时、重试、审计和结果验证。

## 风险策略

- 只读查询：满足权限和参数要求后自动执行。
- 低风险动作：默认自动执行，可由策略覆盖。
- 封禁 IP、隔离终端：真实模式可配置审批，仿真模式自动执行。
- 禁用账号等高风险动作：真实模式默认审批，仿真模式可自动执行。

## 安全约束

- 工具使用严格结构化参数，不接受任意 Shell 或模型生成代码。
- 调用前检查证据引用、目标身份、预期效果和回滚策略。
- 高风险失败不得盲目重复，先查询当前状态再决定重试。
- 使用幂等键避免重复封禁、隔离或禁用。
- 支持暂停、取消、恢复、紧急停止及全局自动化关闭。
- 工具结果属于不可信输入，进入模型前执行提示注入隔离和数据清洗。

## 已实现边界

- 固定六工具注册表覆盖防火墙、终端和账户的变更/查询配对，版本与参数 Schema 不允许客户端扩展。
- SQLAlchemy 持久化对调用、策略、审批、租约、尝试、验证和控制事件使用 tenant-bound 查询与追加审计；并发更新使用 revision/CAS。
- 变更工具超时一律视为结果未知，不自动重试；只有只读失败可在固定上限内重试。
- 离线仿真适配器只操作显式 allowlist 状态，不联网、不执行 Shell、不接收凭据或模型上下文。
- 编排器只接受实际 `TrustedToolCall` 与同调用 `ToolVerification`；仅 `succeeded + verified` 可进入验证角色，其余终态进入人工复核。
- HTTP 端点从服务端绑定租户与主体，只接受业务决定/原因；公开轨迹不包含原始结果、令牌摘要、租户主体或私有推理。

## 当前限制

阶段 5 只验收单机 SQLite 与离线仿真适配器。真实防火墙、EDR、IAM 连接器及其凭据管理、生产级数据库并发和授权环境验证尚未实现；任何离线 smoke 结果都不能作为真实设备执行证明。
