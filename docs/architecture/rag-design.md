# RAG 设计

> 文档状态：当前参考（更新于 2026-09-04）。RAG 同时服务于知识检索智能体和智能助手。

## 数据来源

- 用户上传并发布的本地知识库文档；
- 经清单校验的内置安全垂直知识包，包括监管基线、0day/在野利用响应、MITRE ATT&CK 和维护规范；
- 已完成并允许检索的历史调查报告。

所有知识库、文档版本、分块和索引状态持久化保存，重启后无需重新上传。

## 入库链路

内置知识包在进入普通入库链路前先执行信任校验：清单结构必须严格匹配，文档路径不能逃逸或使用符号链接，媒体类型和 SHA-256 必须匹配，来源必须是批准机构的 HTTPS 地址，复核期限必须有效。Markdown 摘要还要求每条来源出现在正文；官方原始 PDF 校验 PDF 结构、大小和清单哈希；官方 HTML 快照校验 UTF-8、HTML 结构和清单哈希，解析时优先提取官方正文/目录容器并移除主动内容、导航和页脚。任一文档失败时整包拒绝，不进行部分导入。重复导入按文件名跳过，避免产生无意义版本。导入时还会持久化官方来源等级/URL、核验日期和文档复核截止日期，供检索与助手展示。

1. 文件名、类型、大小和内容安全检查；
2. 格式解析与文本规范化；
3. 标题、段落和长度规则生成候选块；
4. 配置模型时进行 LLM 语义边界优化；
5. 结构化结果校验、偏移修复、去重和质量检查；
6. LLM 失败时使用规则分块并明确记录降级原因；
7. Embedding、BM25 和 Milvus 索引；
8. 发布版本成为默认检索版本。

“LLM 分块失败，已使用规则分块”表示文档入库成功但语义优化失败，不表示 LLM 分块成功。

## 检索链路

1. 查询规范化和可选问题改写；
2. BM25 关键词召回；中文在单字词元之外确定性加入二元/三元词组，保留“网络安全事件”“报告热线”等短语区分度；
3. BGE-M3 向量召回；
4. 融合去重；
5. BGE Reranker 重排；
6. 权限、版本和引用过滤；
7. 证据不足时明确拒答或给出限制。

本地持久化检索可在云链路不可用时继续工作；界面必须显示真实采用的检索模式和降级状态。

## 固定评测链路

知识库页面的“运行评测”只针对当前选中的知识库执行 `shieldchain-security-vertical-v1`，不能跨知识库混用证据。服务端从只读评测目录加载严格 JSON，校验数据集标识与路径边界，然后真实运行 BM25、向量召回和重排，计算 Recall@5、MRR、nDCG、引用正确率、引用精确率、期望引用召回率、抽取式忠实度、拒答准确率、P50/P95、调用次数、失败率和估算费用。质量阈值与实测值一并返回；模型或 Milvus 不可用时保留 BM25 结果、记录失败并使完整门禁失败。

当前本地检索响应采用可验证的抽取式答案：答案正文由实际命中的片段组成，并明确声明只能作为分析依据、不能授权工具执行。逐题评测会验证每个答案片段是否能在引用证据中定位；这项确定性指标不替代未来对 Qwen 生成答案进行语义声明级事实核验。

查询在检索前执行确定性提示注入检查，命中时不返回片段；规则将直接命令与漏洞报告中“可执行任意命令”等事实描述区分，避免把安全研究正文误判为攻击指令。知识块可使用 `[shieldchain-claim:<claim-id>:supports]` 和 `:counters` 声明显式立场；同一声明同时命中两种立场时返回 `conflicting_evidence` 并保留冲突证据供人工复核。

批量评测会复用一次预计算的 BM25 语料统计；向量或重排服务首次确定不可用后，本轮剩余用例停止重复探测，避免线性累积超时，但首次真实失败仍计入调用失败率。

## 智能助手消费边界

智能助手将普通寒暄和安全知识问题分开处理。普通寒暄标记为 `conversational`，不会伪称查询过知识库；安全知识问题只能使用 RAG 命中片段作为生成上下文。回答状态分为有依据生成、生成失败后的抽取式降级和结构化拒答，状态、拒答原因、检索/生成降级与引用会随消息持久化。

助手页面独立展示每条证据的文档名、文档版本、内容块、标题路径、页码或结构位置、融合分数、完整性哈希、官方来源等级/URL和核验/复核日期。超过复核截止日期的受管资料不参与回答；查询只命中过期资料时返回 `stale_evidence`。正文不依赖模型输出的引用编号；生成模型不可用时最多直接展示 3 条原始证据片段，并明确要求人工复核，不把模型故障写成知识库无证据。

助手固定评测从只读目录加载 `shieldchain-assistant-v1`，不创建或污染真实会话；API 为 `POST /api/v1/assistant/evaluations`，页面可查看数据集哈希、阈值、整体指标和逐题失败原因。固定指标包括状态准确率、拒答准确率、期望文档引用召回、来源元数据完整性、用例通过率、生成降级率和 P50/P95。

## 模型与存储

- Embedding：BGE-M3；
- 向量数据库：Milvus；
- Reranker：BGE Reranker；
- 语义分块模型：任意 OpenAI 兼容模型，可为 DeepSeek 或本地 Qwen/vLLM；
- 文档和会话原始数据：本地持久化目录；
- 元数据：SQLite。

## 安全要求

- 不接受远程 URL 或服务端本地路径作为上传输入；
- 检索结果必须携带文档、版本、块号和可公开引用；
- 删除知识库或文档时同步删除关联原文、分块和索引；
- 历史报告进入知识库前执行字段裁剪，不包含凭据、私有提示词和原始敏感载荷；
- 模型输出不能替代来源证据。
- 内置知识包只保存项目组编写的防御性摘要和来源链接；第三方资料的许可与使用条件仍以发布机构页面为准。
- 过期知识包必须先复核、更新清单版本与内容哈希，不能通过修改系统时间或放宽校验继续导入。
