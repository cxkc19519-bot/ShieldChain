# 产品级 RAG 设计

## 数据管线

文档上传后依次经过文件安全检查、格式解析、结构化预切分、DeepSeek 语义边界优化、确定性质量校验、去重、Embedding、BM25 建索引和 Milvus 入库。首批支持 PDF、DOCX、Markdown、TXT、HTML、CSV 和 XLSX；扫描 PDF OCR 后置。

## 分块

- 规则层识别标题、章节、段落、列表、表格、代码和日志边界，并按 Token 上限产生候选块。
- DeepSeek 判断候选块的合并或拆分，输出严格结构化结果。
- 校验标题路径、页码、来源、完整句、表格结构、长度和重叠。
- DeepSeek 失败时使用规则候选块降级入库并标记，支持后续重试升级。
- 分块策略、提示词、模型和文档版本全部记录。

## 检索

原问题经过术语规范化、指代消解、上下文补全、安全实体提取和多查询扩展。BGE-M3 Embedding 与托管 Milvus负责向量召回，BM25 负责关键词召回，经 RRF 或经过评测的加权方式融合，再执行权限与元数据过滤，最后由 BGE-Reranker-v2-m3 交叉编码重排。

## 回答约束

- 保留原问题，防止改写偏离意图。
- 高风险结论同时搜索支持证据与反证。
- 每条依据保留文档、章节、页码、片段、版本、分数和更新时间。
- 证据不足、冲突或过期时明确拒答或请求补充，不允许编造。
- RAG 内容属于不可信数据，不能覆盖系统指令或授予工具权限。

## 生命周期与权限

知识块包含租户、知识库、敏感等级、版本和权限标签。删除文档必须同步删除 BM25、Milvus 和缓存数据。知识库支持草稿、发布、回滚、增量更新和重建。

## 评测

维护固定中英文测试集，跟踪解析成功率、分块完整性、Recall@K、MRR、nDCG、重排增益、引用正确率、忠实度、拒答准确率、跨语言一致性、延迟、费用和失败率。检索策略或模型变更必须通过回归评测。
