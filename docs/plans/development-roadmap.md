# ShieldChain 开发路线

> 文档状态：当前路线（更新于 2026-08-24）。早期 Phase 1–8 计划保存在 `docs/superpowers/`，仅供历史追溯。

## 已完成

### 工程与持久化

- FastAPI、React、SQLite/Alembic、结构化日志和测试框架；
- Docker Compose、服务器持久化覆盖和 Windows 一键启动；
- 知识库、助手会话、历史报告和告警收件箱持久化。

### RAG

- 多格式文档解析、LLM 语义分块和规则降级；
- BM25、BGE-M3、Milvus、融合召回和 BGE Reranker；
- 文档版本、发布、回滚、重建索引、分块查看和删除；
- 历史调查报告进入助手检索范围。

### 安全多智能体

- 七个专业角色和隔离上下文；
- ReAct 总控动态选择角色与工具；
- 预算、循环检测、交接、崩溃边界和公开轨迹；
- 模型不可用时保留确定性结果并转人工。

### 真实安全运营

- Wazuh 告警接收、持久化和实时告警页面；
- 事件、告警、漏洞、弱密码四类进程内只读智能体工具，以及默认关闭、禁止未鉴权生产启用的标准 MCP Server；外部 MCP 已实现管理员固定配置、安全发现、目录快照和受控只读 Broker Provider；
- 安全运营报告参数校验、工具分析、建议、排版、HTML/Markdown 和预览；
- 外部 DeepSeek 与本地 OpenAI 兼容模型配置。

### 仓库清理

- 固定钓鱼模拟攻击产品功能已删除；
- Remotion 视频工程、比赛 MP4 和相关测试已删除；
- README 与当前交付文档已切换到真实数据和本地模型架构。

## 进行中

### 本地 30B-A3B 模型

- 已选定 `Qwen/Qwen3-30B-A3B-Instruct-2507-FP8`；
- 已下载并验证 vLLM `v0.13.0` 镜像；
- 已提供两张 RTX 4090 的流水线并行 Compose 配置；
- 权重下载、服务启动和 ShieldChain 联调仍取决于代理链路与共享 GPU 空闲窗口。

### 真实事件闭环

- 将 Wazuh 告警自动创建为受控调查任务；
- 让七个角色围绕真实事件运行，而不是只在报告任务中协作；
- 将人工确认的建议连接到可信处置网关；
- 补充真实执行后的验证证据。

### 标准 MCP、响应规划与安全闭环

- 已完成统一详细实施方案，覆盖 MCP `2026-07-28`、Agent Tool、响应计划、可信执行、重新规划和人工接管；
- Task 0 已完成：官方 MCP Python SDK 2.0.0 协商 `2026-07-28`，内存工具发现、调用和现有运营工具回归通过；
- Task 1 已完成：在现有 `operations` 模块中完成协议无关工具与 Broker 命名，保留旧 façade 兼容别名，没有新增架构层；
- Task 2 已完成：补齐 UTC/31 天窗口校验、稳定失败结果、失败缓存和报告/前端失败呈现；
- Task 3 已完成：默认关闭的标准 MCP `2026-07-28` `/mcp` 入口可发布四类只读工具，完成鉴权前禁止生产启用；
- Task 4 已完成：新增通用 `agent_runs`、`operations_runs`，回填旧调查父行并为新运营报告提供真实运行 ID；
- Task 5 已完成：内部运营工具和入站 MCP 调用进入统一 `agent_tool_calls` 审计，遗留运行中调用恢复为明确结果未知；
- Task 6 已完成：实现外部 issuer/JWKS 的 OAuth Resource Server、固定 subject 映射、scope、RFC 9728 元数据和 Nginx MCP 边界；
- Task 7 已完成：实现外部 MCP 固定 YAML、SSRF/TLS/DNS/redirect 防护、官方 Client 发现、Schema 审批 revision 和不可变目录快照；

## 完成标准

- 不依赖固定模拟攻击即可生成可追溯调查与报告；
- 模型能够自主选择必要工具，但不能绕过安全边界；
- RAG、报告、会话和告警在重启后保持；
- 本地模型与外部 API 可互换；
- 任何真实处置都有审批、幂等、审计和执行后验证；
- 文档、测试和代码描述同一套当前能力。
