# 开发路线

详细到具体文件和测试的实施计划将在设计规格经用户书面审阅确认后单独编写。本路线定义阶段顺序和退出门槛。

## 阶段 1：工程基础

**状态：已完成（2026-07-13）。** 已通过 Windows 脚本契约、离线测试、完整质量门禁、密钥扫描和未来范围扫描；付费 DeepSeek 实时测试按安全策略跳过。

建立前后端骨架、配置、日志、异常、SQLite、DeepSeek 适配器和测试框架。退出条件是本机可启动、健康检查通过、密钥不进入代码和日志。

## 阶段 2：最小事件闭环

**状态：已完成（2026-07-14）。** 已通过 Alembic 升级/降级/回到 head、后端与前端测试、Windows 脚本合同、独立阶段 smoke 及完整 `verify.ps1`；默认验证未调用 DeepSeek 或真实设备。

以固定仿真数据完成告警、证据查询、规则研判、模拟封禁和验证。退出条件是无需 LLM 也能重复执行确定性闭环。

## 阶段 3：产品级 RAG

**状态：已完成（2026-07-20）。** 文档解析、规则/DeepSeek 语义分块、BGE-M3/Milvus/BM25 索引边界、问题改写、混合召回、BGE Reranker、引用、权限、拒答、固定双语评测、知识 API 和最小知识库页面已经实现。Windows 完整门禁、Alembic 升降升、固定 RAG 评测、脚本合同和阶段 3 离线 smoke 已通过。真实 DeepSeek、Embedding、Milvus 和 Reranker 环境尚未授权，因此本阶段只验收确定性离线替身和失败关闭语义，不宣称真实云链路通过。

阶段 3 只有在 Windows 本机完整后端/前端门禁、Alembic 升降升、固定 RAG 评测、脚本契约、阶段 3 离线 smoke、安全检查、文档和当日开发日志全部通过后，才能标记为已完成并进入阶段 4。任一门禁失败时阶段 4 保持未开始。

## 阶段 4：多智能体与上下文工程

**状态：已完成（2026-07-23）。** Task 1–10 已完成领域/持久化/并发边界、权限与注入隔离、上下文装配、分层记忆、结构化交接、七类离线专业角色、确定性超级智能体编排、只读协作轨迹 API 和最小工作台。完整后端/前端门禁、Alembic 升降升、安全回归、固定 RAG 评测、脚本合同及阶段 3/4 离线 smoke 已通过；阶段 5/6 能力保持未开始。

实现共享案件状态、角色私有上下文、上下文装配器、结构化交接和专业角色；以状态机控制协作。

## 阶段 5：可信工具调用

实现工具注册、策略、审批、幂等、审计、超时、重试和紧急停止，并接入仿真工具。

**状态：进行中（2026-07-23）。** 已确认设计规格与 12 个垂直任务；Task 1 核心领域合同与状态机已完成，下一步为 Task 2 工具注册表与严格参数 Schema。阶段 6 ReAct 保持未开始。

## 阶段 6：ReAct 自主闭环

实现观察、失败分类、重新规划、预算限制和人工接管。

## 阶段 7：完整前端

按运营总览、事件调查、智能体工作台、知识库、处置中心、报告与审计的顺序逐页交付。

## 阶段 8：加固与比赛交付

完成性能、安全、Docker Compose、部署、源代码说明、设计、开发、测试、总结、PPT 和三分钟视频。

## 通用退出门槛

功能验收、自动化测试、安全检查、文档和开发日志全部完成后才进入下一阶段。
